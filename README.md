## Project

The IT Talent Platform is managed through GitHub Projects.

This repository serves as the central source of documentation for the platform, including:

- System architecture and technical design
- Product vision and requirements
- Architectural decisions
- API, database, and security documentation

Documentation must remain consistent with the current implementation of the IT Talent Platform.

When the frontend or backend implementation changes, the relevant documentation should be reviewed and updated accordingly.
